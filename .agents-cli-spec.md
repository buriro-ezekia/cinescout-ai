# CineScout AI — Phase 1 specification

## Purpose

CineScout AI is an evidence-backed pre-production research assistant for filmmakers, producers and screenwriters. The Phase 1 objective is to prove one complete runtime path before introducing a larger multi-agent architecture.

## Phase 1 vertical slice

Given a production brief or screenplay extract, the system must:

1. identify the factual or contextual matters that require external verification;
2. use Gemini through Google ADK to reason about the brief;
3. invoke Parallel Search MCP at runtime for relevant external evidence;
4. distinguish supported information from uncertainty or conflicting evidence; and
5. return a concise production intelligence response with sources and practical implications.

## Tooling

- Google Agent Development Kit (ADK)
- Gemini on Google Cloud / Vertex AI
- Parallel Search MCP
- Agents CLI for local development and later deployment support

## Safety and evidence constraints

The agent must not invent sources, claim that a matter has been verified without external evidence, or present legal, historical or cultural certainty where the available evidence is insufficient. It must make uncertainty visible.

## Phase 1 acceptance criteria

- The repository contains a valid ADK application with a root agent.
- The root agent has a live Parallel Search MCP toolset configured.
- A user can run the agent locally through Agents CLI after configuring Google credentials.
- When a brief contains externally verifiable claims, the agent is instructed to use Parallel before reaching a factual conclusion.
- The output identifies evidence, uncertainty and production implications.
- Automated tests verify the core configuration and guardrails without making paid external calls.
- No secrets are committed to the repository.
